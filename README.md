# 🪖 Toy Soldiers

> **[🎮 Play the Live Game Here](https://explore.m-jayz.com/TS/)**

**Toy Soldiers** is a tactical, turn-based browser strategy game built with vanilla JavaScript, HTML5, and CSS. Command a diverse squad of miniature military units across procedurally generated battlefields, utilizing cover, action points (AP), and strategic positioning to defeat the enemy.

---

## 🌟 Features

* **Turn-Based Tactical Combat**: Command units using an Action Point (AP) economy for movement, attacks, aiming, and special abilities.
* **Diverse Unit Roster**: Choose from Infantry, Machine Gunners, Snipers, Scouts, Medics, Engineers, Mine Specialists, Heavy units, Tanks, Flamer Tanks, and Artillery.
* **Dynamic Battlefield & Cover**: 
  * Procedurally generated maps with forests, hills, water crossings, bridges, and rock formations.
  * Real-time cover mechanics that reduce incoming damage.
  * *Worn Cover*: Cover degrades over time under heavy fire or shelling.
* **Tactical Depth**:
  * **Fog of War & Last-Known Enemy Spots**: Units only see what is within their line of sight.
  * **Flanking & Overrun**: Gain combat advantages from flanks and rear attacks, or ram enemies with armored vehicles.
  * **Overwatch & Stances**: Set units to *Defend*, *Aim*, or *Overwatch* to react during the enemy's turn.
  * **Specialist Actions**: Lay mines, clear paths, call in supply drops, and heal wounded squadmates.
* **Integrated Map Editor**: Create, paint, customize, and export your own battlemaps.
* **Save, Load, & Export**: Persist your campaign progress via local browser storage or file exports.

## 🚀 Running Locally

You can also run the game on your local machine:

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.

> **Note on Sound Assets:** Audio files stream dynamically from the live hosted server (`https://explore.m-jayz.com/TS/`). An active internet connection is required for sound effects when playing a cloned local copy.

---

## 🕹️ How to Play

1. **Deploy**: Select and place your starting units in your deployment zone using your available points.
2. **Start Battle**: Once your squad is ready, click **Done buying — Start Battle**.
3. **Control**: 
   * Click a friendly unit to select it.
   * Review movement paths and click valid cells to move.
   * Attack visible enemies using standard attacks, aimed shots, or grenades.
4. **End Turn**: Finish your moves and pass the turn to let the AI execute its strategy.
